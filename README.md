# Питание 2.0 — офлайн OCR (тестовый исходный проект)

Русская и английская модели Tesseract вложены в APK. Приложение не требует интернет-разрешения.

ВАЖНО: проект не проходил проверку сборки и реального распознавания на Android. Вариант распознавания по фото из камеры пока использует миниатюру, для качества используйте выбор фото из галереи.

Для GitHub: скопируйте СОДЕРЖИМОЕ этой папки в корень репозитория, не оставляйте вложенную папку. Workflow в .github/workflows/build-apk.yml.

Текущий парсер экспериментальный: результат чека на 1317 руб. не подтверждён. Не используйте для финансового учёта без проверки каждой позиции.
